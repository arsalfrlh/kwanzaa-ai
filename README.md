how to user
step 1: install all library and framework
step 2: train the ai "python train.py"
step 3: running the api "python api.py"
step 4: running laravel "php artisan serve" | running flutter "flutter run"
last step: you can running the program in web(laravel) and mobile(flutter)

#note
You can set the AI ​​chatbot response simply by setting it in the intents.json file, if you have done that then run the command "python train.py"
